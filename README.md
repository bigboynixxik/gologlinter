# Log Linter (Selectel Test Task)

Линтер для проверки стандартов лог-записей в Go (log/slog, go.uber.org/zap).
Совместим с `golangci-lint` как кастомный плагин.

## Реализованные правила
1. Сообщения начинаются со строчной буквы (поддерживается авто-исправление `SuggestedFix`).
2. Сообщения только на английском языке.
3. Сообщения не содержат спецсимволов и эмодзи.
4. Отсутствуют чувствительные данные (password, token, api_key).

## Бонусные задания
- [x] **Конфигурация**: паттерны чувствительных данных настраиваются через флаг `-sensitive`.
- [x] **Авто-исправление**: Suggestion для перевода первой буквы в нижний регистр.
- [x] **Кастомные паттерны**: передаются списком через запятую.
-[x] **CI/CD**: Настроен GitHub Actions для прогона тестов и сборки.

## Как собрать плагин
```bash
go build -buildmode=plugin -o plugin.so plugin/plugin.go
```
#### Примечание: Сборка плагина через ```-buildmode=plugin``` поддерживается только на Linux и macOS. Для проверки на Windows рекомендуется использовать unit-тесты (go test ./...)."
